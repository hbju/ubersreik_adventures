## Difficulty

The GM assigns a **Difficulty modifier** to Tests to reflect how hard a task is. Published adventures specify these; otherwise the GM adjudges on the fly.

### Difficulty Table

| Difficulty | Modifier |
|---|---|
| Very Easy | +60 |
| Easy | +40 |
| Average | +20 |
| Challenging | +0 |
| Difficult | –10 |
| Hard | –20 |
| Very Hard | –30 |

> **Example:** Valentyn tracks a stag under normal conditions: **Average (+20) Track** Test against his skill of 41, so he rolls against **61**. But last night's rain washed away the tracks; the GM rules this **Very Hard (–30)**, reducing the target to **11** (41–30=11). Valentyn rolls a 35 — failure.
