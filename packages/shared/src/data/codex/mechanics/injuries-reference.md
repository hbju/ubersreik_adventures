## Injuries Reference

### Broken Bones

**Minor:** Bone is fractured but still aligned. The Hit Location is unusable.
- Arm/Leg: treat as lost limb (see Amputated Parts).
- Head: liquid diet only; **–30** to Language Tests.
- Body: **–30** to Strength and Agility; halved Move.
- Heals in **30+1d10 days**. Successful **Average (+20) [Endurance](/codex/skills/endurance)** Test at the end = no long-term effects. Failure = permanent **–5** to relevant Agility/Language Tests. A **Heal** Test within one week negates the need for the Endurance Test.

**Major:** Bone badly broken or splintered. Same effects as Minor but all Tests are **Challenging (+0)** and healing takes **10 days longer**. Failure penalties increase to **–10**.

### Torn Muscles

**Minor:** Suffer **–10** to all Tests using the affected location. Leg hits also halve Movement. Heals partially in **30 – Toughness Bonus days** (one use of **[Heal](/codex/skills/heal)** reduces recovery by 1 day + SL).

**Major:** Suffer **–20** to all Tests using the affected location. Heals to **–10** after **30 – TB days**; fully heals after another **30 – TB days**.

### Amputated Parts

When a result calls for **Amputation (Difficulty)**, make an **[Endurance](/codex/skills/endurance)** Test at the listed Difficulty:
- Fail: gain [Prone](/codex/condition/condition_prone).
- Fail by **–2 or worse**: also gain [Stunned](/codex/condition/condition_stunned).
- Fail by **–4 or worse**: also gain [Unconscious](/codex/condition/condition_unconscious).

All amputations require **Surgery**; 1 Wound cannot be healed until a surgeon treats it.

#### Amputation Penalties by Part

| Part | Penalty |
|---|---|
| **Arm** | As lost hand; cannot strap shield to the arm. |
| **Ear** | Losing both: permanent **–20** to hearing Perception Tests; **–5 Fellowship** per lost ear when visible. |
| **Eye** | Losing both: **–30** to sight-based Tests; **–5 Fellowship** per scarred socket when visible. |
| **Fingers** | Each lost finger: relevant failed Tests with a units die equal to or below number of lost fingers count as Fumbles; **–5** to Tests using that hand per finger. 4+ fingers lost = treat as lost hand. |
| **Foot** | Permanent halved Move; **–20** to mobility-dependent Tests (e.g., [Dodge](/codex/skills/dodge)). |
| **Hand** | **–20** to two-handed Tests; cannot wield two-handed weapons; can strap shield to the arm. If primary hand, **–20** to Melee Tests with secondary hand (reduce by 5 per 100 XP spent retraining). |
| **Leg** | As lost foot, but cannot use [Dodge](/codex/skills/dodge) at all. |
| **Nose** | Permanent **–20 Fellowship**; **–30** to smell-based Tests. |
| **Teeth** | **–1 Fellowship** per 2 teeth lost; eating difficulties once more than half are lost. |
| **Toes** | Permanent **–1 Agility** and **–1 Weapon Skill** per toe lost. |
| **Tongue** | Auto-fail all spoken Language Tests. |
