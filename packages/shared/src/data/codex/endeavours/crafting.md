### Crafting

Rather than commissioning someone else, fashion your own trappings using your **Trade Skills**. You require appropriate **Trade Tools**, **raw materials** (typically costing **one quarter** of the item's list price), and access to a suitable workshop.

Attempt an **[Extended](/codex/mechanics/extended-tests) [Trade Test](/codex/skills/trade)**, with Difficulty set by the item's Availability:

| Availability | Difficulty |
|---|---|
| Common | Average (+20) |
| Scarce | Challenging (+0) |
| Rare | Difficult (–10) |
| Exotic | Very Hard (–30) |

The **SL required** to complete the Test is set by the item's list price, modified by any Qualities or Flaws you build in. Each Flaw **halves** the SL required; each Quality adds **+5 SL** (calculated after halving for Flaws).

| List Price | Base SL Required |
|---|---|
| Brass | 5 |
| Silver | 10 |
| Gold | 15+ |

Each Endeavour spent on Crafting allows **one roll** toward the Extended Test. Unfinished work may be stored or carried between adventures.
